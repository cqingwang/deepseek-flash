# NVIDIA Sync[#](#nvidia-sync "Link to this heading")

## Overview[#](#overview "Link to this heading")

NVIDIA Sync is a utility for Windows, macOS, and Ubuntu that streamlines access to your DGX Spark from a laptop or workstation.

It manages SSH connections, port forwarding, and tunnels in the background so you can work on your DGX Spark without manually running commands in a terminal.

- Learn more in the [NVIDIA Sync User Guide](https://docs.nvidia.com/sync/latest/index.html).
- [Download and install NVIDIA Sync](https://build.nvidia.com/spark/connect-to-your-spark/sync).

## Key Capabilities[#](#key-capabilities "Link to this heading")

- **Direct connections**: Add a device on your local network using device discovery, a hostname or IP address, or an imported SSH alias. Refer to [Direct Connections](https://docs.nvidia.com/sync/latest/direct-connections.html) in the NVIDIA Sync User Guide.
- **Tailscale connections**: Access your DGX Spark when you are not on the same network. Refer to [Tailscale Connections](https://docs.nvidia.com/sync/latest/tailscale.html) in the NVIDIA Sync User Guide.
- **Applications**: Launch supported IDEs, tools, and custom scripts on your DGX Spark with a click. Refer to [Applications](https://docs.nvidia.com/sync/latest/applications.html) in the NVIDIA Sync User Guide.
- **Cluster Assistant**: Cluster your DGX Spark systems without manually running commands in a terminal. Refer to [Cluster Assistant](https://docs.nvidia.com/sync/latest/cluster-assistant.html) in the NVIDIA Sync User Guide. For physical cable requirements and ConnectX-7 network background, refer to [ConnectX-7 Networking](spark-clustering.html#spark-clustering-topic).

## Using NVIDIA Sync with Your DGX Spark[#](#using-nvidia-sync-with-your-spark "Link to this heading")

To get started with NVIDIA Sync:

1. Install NVIDIA Sync on your laptop.
2. Add your DGX Spark to NVIDIA Sync.
3. Launch an application on your DGX Spark through NVIDIA Sync.

For step-by-step installation and onboarding instructions, refer to [Getting Started](https://docs.nvidia.com/sync/latest/getting-started.html) in the NVIDIA Sync User Guide.
